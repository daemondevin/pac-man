Port and let Portable!

Version 3.0

PAC-MAN (PortableApps Compiler & Management) is a launcher framework built on top of the PortableApps.com Launcher (PAL). It's aimed at the apps PAL deliberately doesn't target: programs that need services, drivers, DLL registration, file associations, firewall rules and other changes to Windows. Learn more at the GitHub Project page

Its core promise is that every change can be undone. Before a launcher changes anything on the computer, it records how to undo it in a journal. When the app closes, the journal puts everything back. After a crash, a power cut or a pulled USB drive, the next launch finds the journal and finishes the job.

Getting started

  1. Start PortableAppsCompiler.exe, in the same folder as this page. You don't need to install anything.
  2. To use it from the PortableApps.com Platform, put this folder in the Platform's PortableApps folder. The Platform is optional.
  3. Use it to make your own portable applications!
